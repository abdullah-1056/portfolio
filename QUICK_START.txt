STEP 1: CREATE SUPABASE BUCKET (1 minute)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open Supabase: https://kvlblcgllmjeworkrivx.supabase.co
2. Click "SQL Editor" in left sidebar
3. Click "New Query"
4. Open file: create-resumes-bucket.sql
5. Copy ALL content
6. Paste into SQL Editor
7. Click "Run" button (or Ctrl+Enter)
8. Should see: "Success. No rows returned"

✓ Done! Bucket created.


STEP 2: UPLOAD YOUR RESUME (30 seconds)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Run dev server: npm run dev
2. Open: http://localhost:5173/mgmt-a7f3k9
3. Click "◆ Header" in left sidebar
4. Scroll down to "Resume" section
5. Click "Choose File"
6. Select your resume PDF
7. Wait for "✓ Resume uploaded successfully"

✓ Done! Resume uploaded.


STEP 3: TEST DOWNLOAD (10 seconds)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open homepage: http://localhost:5173
2. Look for "DOWNLOAD RESUME →" button (hero section)
3. Click button
4. Resume should download

✓ Done! Everything working.


WANT TO DELETE AND RE-UPLOAD?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to admin: http://localhost:5173/mgmt-a7f3k9 → ◆ Header
2. Click "DELETE" button (red button next to "View Resume →")
3. Confirm deletion
4. Click "Choose File" again
5. Upload new PDF

✓ Done! New resume uploaded.


TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Error: "Bucket 'resumes' not found"
   → Run SQL in Step 1 again

❌ Resume not downloading
   → Check admin panel has "View Resume →" link
   → Make sure you uploaded a PDF file
   → Try clicking "View Resume →" to open directly

❌ Upload fails silently
   → Press F12 → Console tab to see errors
   → Make sure file is PDF format
   → File must be under 50MB
